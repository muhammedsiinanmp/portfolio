# Portfolio

My first personal site, built while learning the foundations of HTML, CSS and
JavaScript. It's kept here as a record of where I started.

**Live:** [muhammedsiinanmp.github.io/portfolio](https://muhammedsiinanmp.github.io/portfolio/)

Built with HTML, CSS and Bootstrap 5, and hosted on GitHub Pages.

It includes a W3Schools navbar clone and a Booking.com clone. To run it locally,
open `index.html` in a browser.
